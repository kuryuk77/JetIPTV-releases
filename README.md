# JetIPTV

Android TV ve Google TV için medya oynatıcı. / A media player for Android TV and Google TV.

JetIPTV hiçbir kanal, film, dizi, yayın listesi veya abonelik içermez; kullanıcı kendi IPTV hizmetinin bilgilerini girer.
JetIPTV does not include any channels, movies, series, playlists or subscriptions; users add their own IPTV service.
